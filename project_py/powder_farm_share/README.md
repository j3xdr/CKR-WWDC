# Cookie Run — Magic Powder Farm

สคริปต์ปั๊มผงเวทมนตร์ (Magic Powder) อัตโนมัติ — ซื้อสมบัติ (treasure) ของคุกกี้/เพ็ทที่คุณมี Lv.8
ด้วยเหรียญ แล้วย่อยทิ้งเพื่อรับผงเวทมนตร์ทันที วนซ้ำอัตโนมัติจนกว่าจะได้ครบตามเป้าหมาย

ไฟล์ในโฟลเดอร์นี้มีแค่ 3 อย่าง ไม่ต้องโหลดอะไรเพิ่ม:
- `powder_farm.py` — ตัวสคริปต์หลัก (ไฟล์เดียวจบ)
- `treasure.json` — ฐานข้อมูลสมบัติทุกชิ้นในเกม (ชื่อ/ราคา/ผลผลิตผง) — **ต้องอยู่โฟลเดอร์เดียวกับ powder_farm.py เสมอ**
- `requirements.txt` — รายการไลบรารีที่ต้องติดตั้ง

---

## วิธีติดตั้ง (ทำครั้งเดียว)

1. ติดตั้ง Python 3.9 ขึ้นไป ถ้ายังไม่มี — โหลดได้ที่ https://python.org (ตอนติดตั้งบน Windows
   อย่าลืมติ๊ก "Add Python to PATH")
2. เปิด Terminal / Command Prompt แล้ว `cd` เข้ามาที่โฟลเดอร์นี้ (ที่มีไฟล์ 3 อย่างด้านบน)
3. รันคำสั่ง:
   ```
   pip install -r requirements.txt
   ```

## วิธีใช้งาน

1. เปิดไฟล์ `powder_farm.py` ด้วยโปรแกรมแก้ไขข้อความอะไรก็ได้ (Notepad, VS Code, ...)
2. แก้ส่วน `CONFIG` ที่อยู่ด้านบนสุดของไฟล์:

   ```python
   EMAIL    = "your_email@example.com"     # เปลี่ยนเป็นอีเมลบัญชี Cookie Run ของคุณ
   PASSWORD = "your_password"              # เปลี่ยนเป็นรหัสผ่านของคุณ

   TREASURE_NAME = ""            # พิมพ์ชื่อสมบัติที่ต้องการฟาร์ม (ต้องเป็น full name ตรงเป๊ะ
                                  # ไม่สนตัวพิมพ์เล็ก/ใหญ่) เช่น "Holy Feather"
                                  # เว้นว่างไว้ ("") = ใช้ "Revival Boots" (ของ Pirate Cookie)
                                  # เป็นค่าเริ่มต้น (สมบัติราคาถูกที่สุดที่ทดสอบแล้ว)

   POWDER_TARGET  = 10000        # ต้องการผงเพิ่มเท่าไหร่ (นับจาก 0 ตอนเริ่มรัน)
   DRY_RUN        = False        # True = แค่โชว์แผนงาน (เจอสมบัติอะไร ราคาเท่าไหร่) ไม่ส่งอะไรจริง
   ```

   **สำคัญ:** สมบัติที่เลือกต้องเป็นของคุกกี้หรือเพ็ทที่คุณมีอยู่แล้ว **และเลเวลถึง 8** เท่านั้น
   ถ้ายังไม่ถึง สคริปต์จะแจ้ง error ให้ทราบชัดเจนตอนรัน ไม่เสียเหรียญ

3. บันทึกไฟล์ แล้วรันด้วยคำสั่ง:
   ```
   python powder_farm.py
   ```
4. สคริปต์จะ login เข้าเกม แสดงชื่อสมบัติ/ราคา แล้วเริ่มวนซื้อ-ย่อยอัตโนมัติ พิมพ์ความคืบหน้า
   ให้ดูทุก 5 รอบ (แก้ `PRINT_EVERY` ได้) จนกว่าจะได้ผงครบตาม `POWDER_TARGET` หรือกด `Ctrl+C`
   เพื่อหยุดเองได้ตลอดเวลา

## จะรู้ชื่อสมบัติ (Treasure) ได้ยังไง

เปิดไฟล์ `treasure.json` ด้วยโปรแกรมแก้ไขข้อความ แล้วหาช่อง `"name"` — พิมพ์ชื่อนั้นให้ตรงเป๊ะ
ใน `TREASURE_NAME` (ตัวพิมพ์เล็ก/ใหญ่ไม่เป็นไร) แต่ละชิ้นเป็นของคุกกี้/เพ็ทตัวหนึ่งที่ Lv.8 —
ดูช่อง `"image_tag"` เทียบเอา (`tr_ch..` = คุกกี้, `tr_pet..` = เพ็ท) ถ้าไม่แน่ใจว่ามีคุกกี้/เพ็ท
ตัวไหนถึง Lv.8 บ้าง ให้ลองรัน `DRY_RUN = True` ดูก่อน แล้วค่อยลองเปลี่ยนชื่อจนกว่าจะเจอตัวที่ใช้ได้
(หรือปล่อยว่างไว้ใช้ Revival Boots เป็นค่าเริ่มต้นก็ได้ ถ้ามี Pirate Cookie เลเวล 8)

## แก้ปัญหาที่เจอบ่อย

| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| `เข้าสู่ระบบไม่สำเร็จ: อีเมลหรือรหัสผ่านไม่ถูกต้อง` | เช็ค EMAIL/PASSWORD ใน CONFIG ให้ตรง — ต้องเป็นอีเมล/รหัสผ่านที่ใช้ล็อกอินเกม (DevPlay), ไม่ใช่ Facebook/Google |
| `ต้องมีคุกกี้/เพ็ทเจ้าของสมบัติ ... ที่เลเวลสูงสุด (Lv.8)` | คุณยังไม่มีคุกกี้/เพ็ทของสมบัตินั้นที่ Lv.8 — เลือก `TREASURE_NAME` เป็นตัวอื่นที่คุณมี Lv.8 แล้ว |
| `ไม่พบ treasure ชื่อ ... ใน treasure.json` | พิมพ์ชื่อผิด/ไม่ตรง — เปิด treasure.json เช็คชื่อที่ถูกต้องอีกครั้ง (copy-paste มาเลยจะชัวร์สุด) |
| `treasure.json not found next to powder_farm.py` | ไฟล์ 2 ไฟล์ต้องอยู่โฟลเดอร์เดียวกันเสมอ อย่าย้าย/ลบ treasure.json ทิ้ง |
| ค้าง/ไม่มีอะไรขึ้น | เช็คว่าเน็ตต่ออยู่ กด Ctrl+C แล้วลองรันใหม่ได้ |

## หมายเหตุ

- สคริปต์นี้เป็นเครื่องมือเสริมที่ไม่เป็นทางการ (ไม่ใช่ของ Devsisters) ใช้ตามความเสี่ยงของตัวเอง
- ไม่มีการบันทึกไฟล์ใดๆ ลงเครื่องเลยนอกจากที่คุณเห็นในโฟลเดอร์นี้ — รหัสผ่านของคุณไม่ถูกส่งไปที่ไหน
  นอกจากเซิร์ฟเวอร์เกมโดยตรง (เหมือนตอน login ผ่านแอปจริง)
- แนะนำให้เริ่มด้วย `POWDER_TARGET` น้อยๆ ก่อน (เช่น 500-1000) เพื่อลองดูว่าใช้งานได้ตามที่ต้องการ
  ก่อนตั้งเป้าหมายใหญ่
