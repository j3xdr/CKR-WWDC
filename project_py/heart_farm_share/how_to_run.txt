============================================
คำสั่งรัน Heart Farm (heart_farm.py)
============================================

1. ติดตั้งไลบรารีที่จำเป็น (ทำครั้งแรกครั้งเดียว):
   pip install -r requirements.txt

2. รันสคริปต์:
   python heart_farm.py

* หมายเหตุ: อย่าลืมเปิดไฟล์ heart_farm.py เพื่อตั้งค่า EMAIL และ PASSWORD ของคุณก่อนรัน
