# Cookie Run — Heart Farm Bot

สคริปต์ปั๊มหัวใจ (heart/life) อัตโนมัติ — สร้างเพื่อน guest ชั่วคราวจำนวนมาก ให้แต่ละคนส่งหัวใจให้คุณ
1 ดวง เก็บหัวใจ แล้วลบเพื่อน guest ทิ้งอัตโนมัติ วนซ้ำจนกว่าจะได้หัวใจครบตามเป้าหมาย
เพื่อนจริงในลิสต์ของคุณจะไม่ถูกแตะต้องเลย (ระบบแยกแยะ guest จากเพื่อนจริงอัตโนมัติ)

ไฟล์ในโฟลเดอร์นี้มี 4 อย่าง ไม่ต้องโหลดอะไรเพิ่ม:
- `heart_farm.py` — ตัวสคริปต์หลัก (ไฟล์เดียวจบ)
- `_descriptors.bin` — นิยามโปรโตคอลของเกม (ไฟล์ไบนารี) — **ต้องอยู่โฟลเดอร์เดียวกับ heart_farm.py เสมอ ห้ามเปลี่ยนชื่อ**
- `requirements.txt` — รายการไลบรารีที่ต้องติดตั้ง
- `README.md` — ไฟล์นี้

---

## วิธีติดตั้ง (ทำครั้งเดียว)

1. ติดตั้ง Python 3.9 ขึ้นไป ถ้ายังไม่มี — โหลดได้ที่ https://python.org (ตอนติดตั้งบน Windows
   อย่าลืมติ๊ก "Add Python to PATH")
2. เปิด Terminal / Command Prompt แล้ว `cd` เข้ามาที่โฟลเดอร์นี้ (ที่มีไฟล์ 4 อย่างด้านบน)
3. รันคำสั่ง:
   ```
   pip install -r requirements.txt
   ```

## วิธีใช้งาน

1. เปิดไฟล์ `heart_farm.py` ด้วยโปรแกรมแก้ไขข้อความ (Notepad, VS Code, ...)
2. แก้ส่วน `CONFIG` ด้านบนสุดของไฟล์:

   ```python
   MAIN_EMAIL    = "your_email@example.com"   # เปลี่ยนเป็นอีเมลบัญชี Cookie Run ของคุณ
   MAIN_PASSWORD = "your_password"             # เปลี่ยนเป็นรหัสผ่านของคุณ

   TARGET_HEARTS = 100          # ต้องการหัวใจกี่ดวง (รวมทั้งหมด ระบบวนหลายรอบให้เอง)

   PROXY_URL = "..."             # หรือใส่ URL proxy ไว้ในนี้ หรือกด Enter ใส่ตอนรันสคริปต์ได้
   ```

3. บันทึกไฟล์ แล้วรัน:
   ```
   python heart_farm.py
   ```
4. สคริปต์จะถาม Proxy URL (ถ้าไม่มีให้กด Enter ข้ามได้เลย) จากนั้นจะ login เข้าเกม แล้วเริ่มสร้าง-แอด-เก็บหัวใจ-ลบเพื่อน วนอัตโนมัติจนกว่าจะครบ
   `TARGET_HEARTS` พิมพ์ความคืบหน้าให้ดูตลอด กด `Ctrl+C` เพื่อหยุดเองได้ทุกเมื่อ

## เรื่อง Proxy

การสร้างบัญชี guest จำนวนมากรัวๆ จาก IP เดียว จะโดนเซิร์ฟเวอร์ล็อกอินของเกม **จำกัดจำนวน
(rate-limit)** หลังจากสร้างไปได้ไม่กี่บัญชี (ปกติแค่ ~6 บัญชีต่อ IP) เพื่อแก้ปัญหานี้ สามารถใส่
**rotating proxy** (พร็อกซีที่สลับ IP ให้อัตโนมัติทุกครั้งที่ยิง request) ตอนรันสคริปต์ หรือตั้งค่าไว้ใน `PROXY_URL`

proxy นี้ใช้แค่ตอนสร้างบัญชี guest เท่านั้น (การ login เข้าบัญชีหลัก
และการเล่นเกมส่วนอื่นไม่ผ่าน proxy เลย จึงไม่เห็นบัญชี/รหัสผ่านของคุณ)

ใส่ Proxy URL ในรูปแบบ `http://username:password@host:port/` ของผู้ให้บริการที่คุณสมัคร (เช่น Webshare, Bright Data, IPRoyal, ฯลฯ) หรือกด Enter / ใส่ `""` เพื่อปิดการใช้ proxy
ไปเลยก็ได้ (ใช้ได้กับเป้าหมายเล็กๆ แต่พอ TARGET_HEARTS สูงขึ้นจะเริ่มสร้างบัญชีไม่สำเร็จเป็นชุดๆ)

## หัวใจทำงานยังไง / ทำไมถึงหลายรอบ

เกมจำกัดเพื่อนไว้ที่ 300 คน สคริปต์จะเติมเพื่อน guest ให้เต็มที่ว่าง (300 - เพื่อนจริงที่มีอยู่)
ในแต่ละ "รอบ" (session) แลกหัวใจ เก็บ แล้วลบ guest ทิ้งทั้งหมด เพื่อเปิดที่ว่างให้รอบถัดไปใช้ guest
ชุดใหม่ วนแบบนี้จนกว่าจะได้หัวใจครบ `TARGET_HEARTS` — ถ้ารอบไหนได้ไม่ครบ (เช่น guest บางตัวสร้าง
ไม่สำเร็จ) รอบถัดไปจะเก็บส่วนที่ขาดให้เองอัตโนมัติ ไม่ต้องทำอะไรเพิ่ม

## แก้ปัญหาที่เจอบ่อย

| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| `เข้าสู่ระบบไม่สำเร็จ: อีเมลหรือรหัสผ่านไม่ถูกต้อง` | เช็ค MAIN_EMAIL/MAIN_PASSWORD ให้ตรงกับที่ใช้ล็อกอินเกม (DevPlay) |
| `[producer] guest create FAILED` ขึ้นถี่ๆ | proxy ที่ตั้งไว้อาจมีปัญหาชั่วคราว/หมดอายุ ลองใหม่อีกครั้ง หรือดูหัวข้อ "เรื่อง Proxy" ด้านบนถ้าอยากเปลี่ยนไปใช้ proxy ของตัวเอง |
| `_descriptors.bin not found next to heart_farm.py` | ไฟล์ 2 ไฟล์ต้องอยู่โฟลเดอร์เดียวกันเสมอ อย่าย้าย/ลบ `_descriptors.bin` ทิ้ง |
| `no room to make progress` | เพื่อนจริงในบัญชีมีเกือบ/ครบ 300 คนอยู่แล้ว ไม่มีที่ว่างให้เพิ่ม guest — ต้องลดจำนวนเพื่อนจริงก่อน |
| `2 sessions in a row collected 0 hearts -- aborting` | มีปัญหาต่อเนื่อง (proxy/บัญชี) เช็ค log ด้านบนว่ารอบไหน error อะไร แล้วลองใหม่ |
| ช้าหรือค้าง | เช็คว่าเน็ต/proxy ยังใช้ได้อยู่ กด Ctrl+C แล้วรันใหม่ได้ (ความคืบหน้าที่เก็บได้แล้วจะไม่หาย เพราะหัวใจถูกเก็บเข้าบัญชีจริงทันทีที่แต่ละรอบจบ) |

## หมายเหตุ

- สคริปต์นี้เป็นเครื่องมือเสริมที่ไม่เป็นทางการ (ไม่ใช่ของ Devsisters) ใช้ตามความเสี่ยงของตัวเอง
- ไม่มีการบันทึกไฟล์ใดๆ ลงเครื่องเลยนอกจากที่คุณเห็นในโฟลเดอร์นี้ — รหัสผ่านของคุณไม่ถูกส่งไปที่ไหน
  นอกจากเซิร์ฟเวอร์เกมโดยตรง (เหมือนตอน login ผ่านแอปจริง) — proxy เห็นเฉพาะ traffic ตอนสร้างบัญชี
  guest เท่านั้น ไม่เห็นบัญชีหลัก/รหัสผ่านของคุณ
- แนะนำให้เริ่มด้วย `TARGET_HEARTS` น้อยๆ ก่อน (เช่น 20-50) เพื่อลองดูว่าใช้งานได้ตามที่ต้องการ
  ก่อนตั้งเป้าหมายใหญ่
